## 🚀 Featured Projects

### 🎉 [Festa](https://github.com/francisco-pinho/Festa)
3D party game for the PC where phones are the controllers: scan a QR code, nothing to install. Board game with 31 minigames and a motion-controlled Sports mode (bowling, tennis, golf, boxing, baseball) using the phone's accelerometer and gyroscope.
`TypeScript` `Three.js` `Socket.IO` `Electron` `Rapier` `zod`
➡️ [Download for Windows](https://github.com/francisco-pinho/Festa/releases/latest)

### 🛒 [O Lages](https://github.com/francisco-pinho/O-Lages)
Online store for a local supermarket: product catalog, orders and home delivery. Work in progress.
`Next.js` `TypeScript` `Prisma`
